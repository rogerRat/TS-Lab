# 局部窗口匹配与轨迹质量平衡：问题陈述

研究问题的本质是在不移动样本的前提下，通过合适的采样方法构建一个数据流，此数据流是一个顺序的样本构成的集合，最终，这个来自源的样本构成的集合在特征空间中的分布应当尽可能和参考样本集合相同。一个自然而最合适的问题陈述是直接针对样本的：对数据集 $D_{src/ref}$，有轨迹集合 $T$，其中每一条轨迹是 $t_i$，一个轨迹 $t_i$ 根据模型的输入协议可以产生 $n_i$ 个合法的训练样本 $w_{i,j}$。模型的训练依赖于数据流 $d:\{w_1,w_2,\ldots,w_{budget}\}$，目标可以形式化为设计一个采样策略 $\pi$，使得 $d_{src}:\{w_{src,1},w_{src,2},\ldots,w_{src,budget}\}$ 和 $d_{ref}:\{w_{ref,1},w_{ref,2},\ldots,w_{ref,budget}\}$ 尽可能相同或者近似。

相同在这里定义为特征相同或近似。定义特征提取映射 $\mathcal{F}:w_{i,j}\to\mathbf{w}_{i,j}$，则 $d/D_{ref/src}$ 中的每一个样本都有对应的 $\mathbf{w}$，因此得到特征空间集合 $\mathbf{d}_{src/ref}:\{\mathbf{w}_{i,j}\}$，表示在特征空间 $\mathbf{F}$ 里的点集。这里，可以构建一个函数表征当前特征空间的特性，称为空间位置-密度函数 $\rho(\mathbf{x})$，其中 $\mathbf{x}$ 是一个任意空间位置，此密度函数由样本空间的所有样本进行估计。

因此，问题的表述为最小化 $\mathbf{d}_{src/ref}$ 之间的距离 $L(\mathbf{d}_{src},\mathbf{d}_{ref})$，这里的距离可以是 OT 的 $W$ 距离，也可以是在 KDE 得到连续密度后计算的 KL 散度。优化变量是采样策略 $\pi$，其中 $\pi:w_{i,j}\to p_{(w_{i,j})}$。要实现对 $L(\mathbf{d}_{src},\mathbf{d}_{ref})$ 的最小化，也就是实现在 $\mathbf{F}$ 空间的最小化。

然而，一个轨迹能产生多少窗口 $w$ 本质上和轨迹的长度是分不开的，因此，实际上一个轨迹越长，产生的窗口越多，等价于它本身获得了更大的采样权重。然而，至少在下游的评测任务中，评测设计往往使每条轨迹提供固定数量窗口，因此每条轨迹对评测结果的影响相同。若对 $d_{src},d_{ref}$ 采用朴素的所有窗口枚举的方法，实际上等价于为它们增加了基于轨迹长度的权重。为了消除掉这一部分影响，一个方法是基于它们产生的窗口数量进行反归一化，以保证对任意轨迹 $\forall t_i,\sum_{j=1}^{n_i}p_{(w_{i,j})}$ 相等。可知若一个轨迹能产生 $n_i$ 个合法训练窗口，则每一个窗口应当有反归一化概率为 $\dfrac{1}{n_i}$。所以，在 $\pi$ 发生作用之前，每一个在轨迹 $t_i$ 上的第 $j$ 点开始的窗口 $w_{i,j}$ 的被采样概率应当是 $\dfrac{1}{n_i}\times\dfrac{1}{|T|}$。

所以在这样的假设下，流程是对 src、ref 进行所有合法窗口的枚举，然后以所有合法窗口为最小单元和特征空间映射单元，得到二者的 $\mathbf{d}$ 以及对应的分布 $\mathcal{R}_{src/ref}$。然后，通过求解算法以缩放比例 $s$ 为控制变量，优化问题使得二者的空间密度分布差异尽可能小，得到对应的 $s$ 之后，$\pi$ 根据 $s$ 给出每一个窗口样本的被采样概率，至此策略构建完成。

但是直接枚举所有全部窗口是不可行的。因此可行的一个方法是对所有的轨迹做不重叠的分析段划分。定义一个分析段为 $a_{i,k}$，表示在轨迹 $t_i$ 上的第 $k$ 个分析段。分析段的意义是作为窗口分析的代理：对分析段计算的特征 $\mathbf{a}_{i,k}$ 有如下情况，若 $w_{i,j}$ 完全包裹在分析段 $a_{i,k}$ 内，则将分析段的特征值赋给所有被包裹的窗口；如果某一个窗口跨两个分析段，则根据它在两个分析段内的长度进行对应加权。分析段的长度是一个额外指定的超参数。在此情况下，只是简化了窗口的特征计算，实际上产生出的仍然是对窗口级别的空间质量传输。此时， $a$ 只是特征分析的代理，实际上只是依据它给出了多个窗口 $w$ 进入 $\mathbf{F}$ 空间进行分析，此时有多个同一点的窗口 $w$ 和一系列线性移动的窗口 $w$，进行缩放之后虽然不改变位置但是每一个窗口都有可能被分配不一样的缩放，并且也需要对上亿的窗口进行传输计算。所以， $\mathbf{F}$ 的可行对象依然不能是窗口，这里同样以分析段作为代理。

窗口采样按照分析段加权的一般形式为：令 $\ell_{i,j,k}=|w_{i,j}\cap a_{i,k}|$ 为每一个窗口和一个分析段的重叠长度，理想问题陈述下每一个合法窗口的质量天然等同并进行反归一化以避免轨迹长度加权影响 $\dfrac{1}{n_i}$ ，一个等价于对窗口进行抽取的方法是定义每一个分析段 $a_{i,k}$ 的质量是其所有窗口质量和重叠长度占比的乘积 $m(a_{i,k}) = \sum_{j}^{j=j+|a_{i,k}|}\frac{\ell_{i,j,k}}{|w_{1,j}|} \times m(w_{i,j})$ ，这里重叠占比可以是一个小数表示窗口有一部分已经超出了分析段。同理，对于一个分析段，其第一个合法窗口起点也可以超出分析段起点。任何窗口和分析段的重叠都被视为部分归属，因此传递其质量（被采样概率）。因此对窗口的采样可以等价变化为对分析段的采样：首先采样一个分析段 $a_{i,k}$ ，然后在它的所有合法窗口起点（注意这里的合法窗口起点可以在分析段之外，尤其是在左侧；合法窗口起点加上窗口长度的终点也依然可以在分析段之外，否则等价于不允许分段采样）里按照它在此分析段内部的传递质量进行采样，等价于其被采样概率为 $\frac{\ell_{i,j,k}}{\sum\ell_{i,j,k}}$.

考虑极端情况，分析段的长度应该不小于窗口的长度，分析段的最大长度就是轨迹长度。注意到，如果分析段的长度为 $1$，则毫无意义，因为对一个数据点将不会得出任何有效信息。考虑分阶段，就是一个整个轨迹的情况则是现在的方案：直接针对轨迹进行计算，并且将轨迹的特征值赋给所有内部的窗口。这假设内部所有的窗口具有相同的特征，并且在整个轨迹时长范围内，所有的特征不发生变化，是一个在本问题框架下最粗粒度的估计。现在的方案，直接按照轨迹进行缩放和采样，实质上等价于对轨迹内所有的可能合法窗口进行缩放和采样，同时通过“采集一条轨迹后，在里面随机选一个窗口”的方式抹平了所有窗口间的差异，并且通过此机制保证了轨迹的长度不会影响在实际的数据采集流中它产出窗口样本的数量，从而间接保证了轨迹长度并不成为加权因素。
