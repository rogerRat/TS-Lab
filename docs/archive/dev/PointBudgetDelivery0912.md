# 点预算与整单位交付（2026-09-12，当前协议）

> 历史归档：保留当时的设计、操作或实验证据，不作为当前执行指令。当前入口见 `docs/README.md`。

依据实验计划拍板 15 和用户随后两项确认。本页覆盖旧文档中的固定 N 窗交付描述。

## 选择和训练

N 是窗口当量预算，点预算为 `N*(C+H)`；正式参数仍为 N=4096、C=512、H=64。

| 臂 | 实际交付 | 训练批抽样来源 |
|---|---|---|
| RAGS | 召回块按最高返回余弦排名，整块覆盖的原始数据段 | 各交付段内部全部 stride-1 合法起点 |
| trajectory_level / LESS | 按轨迹得分排名，整条轨迹 | 各交付轨迹内部全部合法起点 |
| TSDS | 多项抽样产生的真实轨迹副本，随机打散后整条交付 | 副本内部全部合法起点，重复身份不去重 |
| Random | 槽格无放回抽 N 窗 | 交付的固定 N 窗 |
| LP-Mirror / LTSV | 原生可重叠 top-k N 窗 | 交付的固定 N 窗 |

段/轨迹按单位长度之和累计，首次达到点预算即停，末单位不裁剪。
RAGS 保留原 CRB 对“窗口起点”的划块定义：起点 100～120、W=576 的块，
交付原始点 100～695（1-based inclusive），落盘为 `[99,695)`。
重叠块包络和 TSDS 重复轨迹分别计费，唯一点数另算；不声称各臂新鲜覆盖相等。
召回结果不够预算时报出不足，不擅自扩 B、补随机轨迹或重复 RAGS 块。

TSDS 的 KDE/OT/IVF/多项抽样不变，默认仍多项抽 N 次；副本用独立
`default_rng(seed)` 打散，再按完整轨迹累计到点预算，避免编号前缀偏置。
只有预算前缀真正交付，记录全部原始抽样计数和实际交付副本 ID，二者不能混称。
重复副本实际增加训练采样权重：每份长度 L 的轨迹贡献 `L-W+1` 个起点项。
这不是“计数只作排序权重”，也不再提前均匀抽出 N 个固定窗。
TSDS 参数 64/16/4/.1/5 是用户冻结的本实验参数，不是上游默认。

所有训练批都在上述起点项中均匀有放回抽样，不是先等概率抽轨迹再抽窗。
不跨轨迹或交付段边界；三学生用同一选集、相同训练种子和相同随机序列。
训练总步数仍为 `ceil(4*N/32)`，每轮累计 `ceil(epoch*N/32)` 存储并评测检查点；
不按所有可滑窗数、唯一点数或实际溢出量增加训练步数。损失和 FP32 原生模型实现不变。

## 粒度对照与消融

`trajectory_level` 已改为真正的整轨迹梯度平均，均匀采样数与 RAGS 三份配置预算相同。
先将每条参考轨迹的原始梯度求均值，再平均这些轨迹向量、归一化；源轨迹按与它的余弦排名。
LESS 则先逐参考轨迹归一化，再累加余弦；两者不是同一个参考聚合公式。
旧 576 点等分段、段首一次估值移为 `uniform_segments` 消融，不再冒称轨迹级。
其他段级消融采用相同整段交付；`window_return` 保留其不重叠窗口部署诊断，
返回不足 N 时披露实际返回量，训练步数仍按请求预算 N。
固定块和窗口返回消融同时修正了多源轨迹的全局索引偏移。

## 产物和成本

选集 NPZ schema 为 `point-budget-regions-v1`。区域选集只保存：
`values`（打包的 FP32 原始点）、`offsets`、`regions`（源 ID、0-based 起止）、
`window_length`、`budget_windows`，以及名称、成本和诊断。
副本是 regions 中独立行。`RegionWindows` 使用累计合法起点数映射批索引，
不创建海量 `[全部滑窗数,576]` 矩阵。窗口级继续保存 `windows/ids`。
共享 task manifest 更新至 `rags.shared-selection.v2`。

各臂选集诊断 `delivery`、学生 cell 的 `selection_coverage` 记录：预算点数、
实际交付点数、单位数、唯一点数、重复点数、溢出点数/比例、合法起点项数。
现有 `selection_metrics.jsonl` 继续统一记录冷/热/选集缓存耗时和峰值显存。
数据量曲线对区域使用整单位预算前缀，不再截取前 N 个滑窗。

RAGS 不再创建全池逐窗分数数组或做 disjoint 贪心切窗，直接排序召回块。
这是部署改变附带的计算简化，不把旧固定窗协议的测时宣称为新方法等价加速。
外部四个 `algorithms.py` 与 LP-Mirror/LTSV 方法代码未修改。
