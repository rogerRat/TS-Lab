## 共同的轨迹估计

一条完整轨迹对应语言侧的一条样本。源侧与参考侧都先在轨迹内部均匀播散取窗，
再将每个窗口的原始特征算术平均为一条轨迹的特征，不先逐窗归一化。
参考侧使用所有可用安全轨迹，不再使用 LESS/TSDS 原来的参考 stride/cap。

采样数为 `sum(CRBConfig.budgets(合法起点数))`，包括相同的逐段取整、端点最小数及上限；
在合法起点索引上用等距点取整，包含两端、无重复。默认密度为 `.02 + .02 + .005`。
这是与 RAGS **配置预算**对齐；RAGS 可能没用完 split 预算，不宣称实际计算次数相等。
两臂与主表/曲线的三段密度联动，不再提供 `less_pool_stride`。

均值特征保存 FP32，每条轨迹只有一行。源特征按源池身份元数据、协议、探针路径与投影配置、
三段预算和适配版本命名，跨六任务复用；不读取/反复 hash 数据或权重内容。
旧窗口级 `.npy` 不会命中。缓存命中时实际源计算次数记零，另保留特征生成时的样本数。
参考特征逐任务计算；所有训练仍只用源侧选集。

## LESS

先平均窗口的全参数共享哈希投影梯度，再对每条轨迹的平均梯度做 L2 归一化。
源轨迹得分为它与各参考轨迹的余弦之和（参考轨迹等权，不按长度加权）。
按轨迹得分降序，从轨迹起点依次切不重叠 576 点窗，装满 N 即停。
并列遵循 C4 的固定随机序（seed=5）。
双侧裸 SGD 梯度、单预训练状态、不加 LoRA；这些是拍板 11 的明确适配，不是待补功能。
只能称“适配版 LESS”，不能称原生复现。

## TSDS：重复样本真正进训练

轨迹特征为冻结 Chronos encoder 的窗口均值池化向量，再对轨迹内采样窗求平均。
候选检索和 KDE 检索都恢复锁定上游的 FAISS IVF：
`nlist = int(sqrt(点数)) // 2`，`nprobe = 10`；没有精确 kNN 或自动扩大 nprobe 的后备路径。
堆式 OT 概率分配不变。共享线程控制也限制 FAISS 自带 OpenMP，调用后恢复。

**本实验冻结参数（用户确认，不是上游默认）**：`max_k=64, kde_k=16, sigma=4, alpha=.1, c=5`。
上游锁定版本的 [config.yaml](https://github.com/ZifanL/TSDS/blob/3dfe13953cffaefaeb9d401172e495aa7e0fd775/config.yaml)
为 `5000 / 1000 / .75 / .5 / 5`；用户明确保留实验文档数值并披露差异，不作调参。
两版均把 k 限制到源候选数的 `//10`；结果同时记录请求参数和实际 k。

[上游 tsds.py 第 94–101 行](https://github.com/ZifanL/TSDS/blob/3dfe13953cffaefaeb9d401172e495aa7e0fd775/tsds.py#L94-L101)
使用 multinomial 后，按次数重复写出每个候选编号，没有去重。用户据此明确：

1. 默认按轨迹概率抽 N 次，保留每条轨迹的全部重复份数。
2. 每份轨迹内部切不重叠窗；同一轨迹的不同副本自然产生相同窗口身份。
3. 从完整的重复窗口池**均匀无放回抽 N 项**。无放回针对“副本项”，不是唯一窗口身份。
4. 不按编号截前 N 项，不按计数改成 top-k，也不补入未抽中的轨迹。
5. 这 N 行连同重复身份落盘，三个学生直接读取，不去重。训练 epoch 按 N 行计算。

实现用累计副本数将抽到的虚拟行号映射回轨迹/起点，和实际展开再抽样等价，
不创建海量重复数组。上游多项抽样使用局部 `RandomState(seed)`；窗口副本抽样使用
独立 `default_rng(seed)`，主表固定 seed=7。没有跨训练种子重新选择。
每条轨迹对窗口副本池的贡献为“抽中次数 × 可切窗数”，因此长轨迹占更多窗口项；
这是用户确认的轨迹转固定窗口预算适配，不宣称上游文本代码定义了这一转换。

记录 `trajectory_sample_counts`、`expanded_window_copies`、`unique_windows`、
`duplicate_windows`。学生结果另有唯一覆盖统计；N 不代表 N 个新鲜互不重叠窗口。
FAISS 原版的极小池限制保留：候选至少 20 条才能有两个 OT 邻居，KDE 点云至少 4 点；
不为小测试偷偷换算法。正式池约 1,365 条轨迹；dev 测试使用足够大的合成点云。
