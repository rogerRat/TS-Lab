# 实验记录文档

> 历史归档：保留当时的设计、操作或实验证据，不作为当前执行指令。当前入口见 `docs/README.md`。

以下规定实验记录规范：

- 时间：登记完整当天时间戳，优先使用实验进行时间，其次使用记录时间；最好两者都有。
- 模型：完整登记使用的模型。
- 数据：完整登记训练源数据和参考数据。
- 方法版本：登记方法（如 random、OT、KDE）和 Commit ID；Commit ID **只登记前 8 个字符**，并登记对应的简单解释与提交信息前 10 个字符。
- 结果：以文字形式登记重要结果；不保存任何结果文件。
- 数值：登记具体指标数值和提升比例；全部以 random 为基线，非 random 方法必须同时登记相对 random 的增降百分比。百分比必须紧跟对应指标数值，以括号标注；不允许单列。
- 表格：使用标准 Markdown 表格；同一组实验的所有对比方法必须写在同一张结果表中，便于横向对比；一个结果表只能写一个 Metrics。多种指标必须拆为多个表格，且每个指标表均须包含 random 和全部对比方法；单表不得过宽。
- 分隔：每个实验步骤之间必须以 `---` 分隔。
- 内容：不做分析，只登记结果。

仅登记训练和评估均已完成的实验。实验组按末步评估完成时间严格倒序排列。所有详细评估表均列出已落盘的全部 checkpoint；`test_error=SQL`；表中全部百分比均相对同组 random 基线计算，负值表示指标降低。
