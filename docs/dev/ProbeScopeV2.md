# 已批准探测范围 v2：2026-09-14 实物核查

目标是寻找可改善、相对少被反复使用的任务；下列收益理由均为待验证假设。
数据年代和新benchmark发布时间不能证明未进入模型预训练语料。
不使用最终考试分数挑任务；表中可用性检查仅使用预考试历史。

参数阶段固定3个集合任务：Finland_Traffic/15T、CPHL/H、EWELD_Load/15T。
前两者原始target维度为1，第三者提供更多训练窗口和工业负荷领域覆盖。
三个模型使用相同任务组，分别选择自己的LR/Epoch；开发分数按任务等权、seed配对后平均。
训练池按既有合法窗口采样，并非对各任务训练曝光等权；sampling.json会记录实际N。

任务阶段仍用TimeMoE固定其已选超参，逐个测试下面8个集合任务，选正收益前3个。
用户规定总候选任务数不得超过20，配置校验已强制执行；参数任务必须是候选池子集，不额外计数。
同一来源的不同变量组可能相关，尤其NEM需求与价格；排名不代表8份独立来源证据。

| ID / 范围 | 原始结构与实际可用量 | 纳入理由（收益为假设） |
| --- | --- | --- |
| time_finland_15t / Finland_Traffic/15T | 原生单变量，1条；预考试32160点，全有限 | 2024年道路流量，有本地通勤和日周周期，可能通过后训练学习具体幅度/峰形；单实体结论有限 |
| time_cphl_h / CPHL/H | 原生单变量4条中2条可用，分别2036/1818点；另外2条因历史非有限被跳过 | 海洋叶绿素动力学有领域差异，可检验非交通领域适配；历史较短，效应可能不稳定 |
| time_eweld_15t / EWELD_Load/15T | TIME包装为10通道，10个用户负荷通道均可用，每条19200点 | 每个物理测量是用户耗电，但按严格数据结构口径不称原生单变量；工业/商业与极端天气负荷可能受益于本地适配；2019年数据，不以新鲜度为首要理由 |
| time_nem_demand_5t / OpenElectricity_NEM/5T的5个demand变量 | 原10通道中选5个，各39456点 | 2025年5地区需求，日内结构与地区差异；具体列名锁定于配置 |
| time_nem_price_5t / 同源5个price变量 | 原10通道中选另5个，各39456点 | 近期市场价格与尖峰机制不同于需求，单独评估；噪声可能导致无收益 |
| time_solar_h / Australia_Solar/H | 原3通道中仅solar_63726完整可用，32544点；另2条因历史非有限跳过 | 日夜周期、发电幅度与站点特征可能适配；只有1站，结果覆盖有限 |
| quito_hour / Quito hour全部5指标 | 原5变量，517实体，拆为2585条可用标量序列 | 保留新接入应用流量基准，长历史和业务节律可能适配 |
| quito_min / Quito min全部5指标 | 原5变量，773实体，拆为3865条可用标量序列 | 10分钟分辨率，覆盖较快的业务变化；不是原生单变量 |

“任务ID”是数据集/频率/变量组的集合，不是单一实体或单一窗口。
统一C512/H64，8个验证窗，预考试历史至少1600点。这是本项目开发探测协议，
不是TIME原生short/medium/long全部时长复现。

暂缓/排除：

- ETT和FEV旧任务不入本轮候选。
- SG_Carpark/15T：原生单变量354条，2025年数据，很有价值；但原始固定版本每条历史约155个缺点，
  每段连续有效长度最多约95，当前完整C512/H64窗口协议不可直接用。暂缓，未静默填补标签。
- CPHL/15T、30T：原生单变量，各2条，但均有缺点，最长连续有效段不足1600，暂缓；
  H是它们的降采样版本，也不把它们列作不同数据来源扩大证据。
- EPF electricity price虽为单变量且5条可用，但源自较早的经典电价数据，优先级低于新增领域。
- ECDC/Influenza、月季度宏观、Smart Manufacturing在当前C/H下历史不足，不把缩窗口悄悄当成同协议。
- SG PM2.5、海流、风场原始是多变量，不能仅因拆通道就宣传为原生单变量。

核查依据：实验机固定TIME数据revision `83e3d0b3be28d11c7182bffcc1892d19b36c4da1`，
原始target形状、variate_names、各数据集原生test_length之外的长度/有限值统计；
Quito固定revision `ed4bf8eea27862aa01a063393ee48732910ecd87`。
