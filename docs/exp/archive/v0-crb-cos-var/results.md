# v0-crb-cos-var 结果

最后修改日期：2026-11-10

状态：在 12 条 M5 FOODS_1 轨迹上已完成。该实验在相等锚点预算下比较 Uniform 和原生 CRB 划分。锚点数量为 K=max(2,ceil(N/q))；两个端点均计入 K。Uniform 使用 K 个四舍五入后均匀间隔的锚点。CRB 使用冻结的 v5 策略，将 K-2 个可自由分配的锚点尽可能均匀地分配到 coverage、error-risk 和递归 minimum-kappa 阶段。

全窗口 ChronosTiny LoRA 梯度使用与 v0-crb-reconst-fine 相同的已预热 checkpoint、全新模型种子 0 的 LoRA 初始化（r=8、alpha=16、dropout=0、q/v 目标）、上下文 512、预测 64 和步长 1。每个梯度立即通过 ParameterHashProjector 随机符号 CountSketch（种子 42）投影到 4096 维。未将稠密 LoRA 梯度或完整轨迹投影向量写入磁盘；投影轨迹矩阵按进程在内存中为两个匹配策略保留，并在该轨迹完成后释放。

对于每种方法和每个 q，相邻锚点定义区间。严格内部排除两个锚点。重建的代表方向是两个已知端点投影梯度算术平均的方向。每个块分数是该代表方向与区间严格内部真实投影梯度之间的平均 1-余弦。分数越低表示方向离散度越小。q=1 没有严格内部，因而未定义。主要聚合是每条轨迹等块均值的等轨迹均值。窗口加权聚合也一并报告，因为 CRB 块大小可变。配对胜计数的是命名方法具有更低等块均值的轨迹数。

按等块均值，CRB 在 q=2,8,16,32,64,128 时更低；Uniform 在 q=4 时更低。轨迹胜数在 q=2 和 q=4 时不同，此时等轨迹平均不代表轨迹多数。按内部窗口加权均值，Uniform 在所有非平凡 q 时更低。两种聚合规则回答不同问题：等块加权给予每个区间同等影响，而窗口加权给予更长的区间更多影响。CRB 产生可变的区间长度，因此两者都有意义。前四条轨迹在每个 q>1 的等块平均上都偏向 CRB，但 12 轨迹的 q=4 结果反转；更大的样本暴露了轨迹和聚合的变异性。

该结果对 12 条选定 FOODS_1 序列和一个固定、全新初始化的 LoRA 模型状态是描述性的。在 q=2 时，每个区间只有一个严格内部向量，因此尽管区间定义简单，两个已知端点的均值仍可能是较差的代表。q=1 没有目标点。不产生跨家族或已训练适配器的结论。

验证：12 个轨迹完成标记和聚合 .complete 存在；trajectory_summary.csv 包含 192 行（12 条轨迹 x 8 个 q 值 x 2 种方法）；aggregate.json 包含 16 个方法-预算行；不存在稠密梯度缓存。监控的 GPU 内存峰值约为 0.9 GiB，cgroup 内存约为 62 GiB 中的 15 GiB，且两个轨迹进程并发运行。早先仅 Uniform 的诊断为排除项，单独保存在 outputs/train/v0-crb-cos-var-uniform-preview/ 下。

产物：outputs/train/v0-crb-cos-var/aggregate.json、trajectory_summary.csv，以及逐轨迹 block_metrics.csv 和 summary.json。配置：configs/rage/v0-crb-cos-var.json。入口与队列：scripts/v0_crb_cos_var.py 和 scripts/v0_crb_cos_var_queue.py。

## v0-crb-cos-var

最后修改日期：2026-11-10

在 12 条选定的 M5 FOODS_1 轨迹上完成。对于每个 q，Uniform 与原生等预算 CRB 划分在真实梯度锚点之间定义区间。代表方向是两个已知投影端点梯度的均值；每个块分数是到 4096d 严格内部真实投影梯度的平均 1-余弦。按等块、等轨迹均值，CRB 在 q=2,8,16,32,64,128 时更低，Uniform 在 q=4 时更低。按内部窗口加权均值，Uniform 在每个 q>1 时更低。两者均报告，因为 CRB 区间长度可变。q=1 没有内部，因而未定义。完整方案和结果：docs/exp/v0-crb-cos-var/results.md。未保留任何完整梯度或投影轨迹。
