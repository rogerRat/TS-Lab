# v0-proxy-dp-segmentation

最后修改日期：2026-11-10

## 问题与方法

精确的 proxy 方差划分是否会比等数量均匀划分改善真实梯度区间指标，以及按区间长度加权 proxy 目标是否会改变这种权衡？该运行使用四条最长的保留源轨迹（序号 01、05、06、09；N=1388、1393、1393、1394）。每种方法对每条轨迹使用 K=ceil(N/64)=22 个区间。因此均匀区间长度是 63 或 64。DP 区间最小长度为 16，无最大长度限制。

每四个起点采样的输出头梯度以 BF16 进行线性重建。精确 DP 优化 (a) sum_j V_j 或 (b) (1/N) sum_j |I_j| V_j，其中 V_j 是区间 j 内重建 proxy 向量的总体协方差迹。Gram 乘积使用带 FP32 累加的坐标分块。真实全梯度指标来自保留的 BF16 缓存，以四个起点为块读取并使用 FP32 归约。未计算任何新梯度。

区间指标除非标识为窗口加权，否则为等区间平均。方向离散度是每个真实梯度与区间平均梯度方向之间的平均 1-余弦。窗口加权方向离散度将每个区间的方向离散度按其起点数量加权。下文的值先在每条轨迹内平均，然后在四条轨迹间等权平均。它们是对此选定四轨迹样本的描述性结果。

## 解释

未加权 DP 在全部四条轨迹上降低了等区间相对方差、等区间方向离散度和等区间绝对方差。其平均窗口加权方向离散度在全部四条轨迹上均高于均匀划分。窗口加权 DP 在全部四条轨迹上降低了等区间相对方差和等区间方向离散度，而其窗口加权方向离散度和绝对方差在全部四条轨迹上均更高。因此，方差目标改善了一些真实梯度判据，但并未支配所有报告的判据。在此样本中，按区间长度加权 proxy 目标并未使窗口加权方向离散度低于均匀划分。

这两个目标编码了不同的偏好。未加权目标给予每个区间同等影响，因此长区间可以携带较大的逐区间方差而不承担成比例的长度惩罚。加权目标按区间长度缩放每个区间方差。两个目标都不直接最小化真实梯度方向离散度。这些结果并不确立超出四条选定长轨迹的普遍收益。

## 产物与验证

对于每个目标，interval_metrics.csv 包含 176 个区间行（22 个区间 x 2 种方法 x 4 条轨迹），summary.json 包含八个轨迹-方法行，四条逐轨迹 checkpoint 存在，且 .complete 存在。验证确认每种方法和每条轨迹恰好有 K 个区间、对 [0,N) 的精确连续覆盖、长度至少为 16，且报告的指标有限。

- 未加权：outputs/train/v0-proxy-dp-segmentation-longest4-unweighted/
- 窗口加权：outputs/train/v0-proxy-dp-segmentation-longest4-window/
- 实验方案：docs/EXP.md 和 configs/rage/v0-proxy-dp-segmentation.json
- 重放日志：logs/v0-proxy-dp-segmentation/longest4.log

在结果验证后，所有原始 BF16 全梯度源缓存及其缓存完成标记于 2026-11-10 根据用户指示被删除。派生 Gram 矩阵、proxy 缓存和结果表仍保留。重放真实梯度指标需要重新生成全梯度向量。

## v0-proxy-dp-segmentation

于 2026-11-10 完成，使用四条最长轨迹（序号 01、05、06、09）的缓存 BF16 梯度，DP 和均匀划分每条轨迹均恰好 22 个区间。未加权 proxy 方差 DP 降低了等轨迹真实相对方差（0.5031 对 0.6762）、等区间方向离散度（0.2995 对 0.4298）和绝对方差（3.7787 对 9.4982），但提高了窗口加权方向离散度（0.5844 对 0.4297）。长度加权 proxy 目标降低了相对方差（0.5717 对 0.6762）和等区间方向离散度（0.3572 对 0.4298），但提高了窗口加权方向离散度（0.4923 对 0.4297）和绝对方差（12.5689 对 9.4982）。这些是对四条选定长轨迹的描述性等轨迹均值；两个目标都未支配所有指标。完整定义和逐轨迹结果：docs/exp/v0-proxy-dp-segmentation/results.md。两个输出树均具有 .complete 标记。原始 BF16 全梯度源缓存在验证后于 2026-11-10 根据用户指示被删除；派生输出和 proxy 缓存仍保留。
