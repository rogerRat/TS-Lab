### 对比结论（预算严格匹配，配对数与两侧锚点数完全相同）

1. **均值（中心偏移）**：CRB 在所有档位都比匹配 uni 更靠近 0、且更正。q=8/16/32/64 的 CRB−uni 均值差为 +0.0062/+0.0039/+0.0094/+0.0115，随 q 增大而扩大；q=64 时 CRB 已转正（+0.00189 vs uni −0.00963）。
2. **负值占比显著下降**：CRB−uni 的负值占比差值为 −0.0347/−0.0175/−0.0661/−0.0684，q=32/64 最明显，CRB 把接近 1/3 的弱负相关配对转成了非负配对。
3. **高相似度富集**：>0.05 占比在 q=32/64 明显提升（CRB−uni = +0.0200/+0.0330）；q=8/16 基本持平（−0.0016/+0.0013）。
4. **标准差**：CRB 标准差在所有档位都比匹配 uni 略小（约 0.0006–0.0055），分布更集中，尾部极端负值（min）总体更浅。
5. 总体方向：在总锚点预算固定为等效间隔 q 的前提下，「cover + 抵消排序分割」相对严格均匀采样，系统性地把分布向非负/高余弦方向平移，且 q 越大效果越明显；q=32（用户默认关注档）的负值占比从 58.5% 降到 51.9%，>0.05 占比从 16.1% 升到 18.1%，均值从 −0.0116 升到 −0.0022。

## 对 REFT 与 source/REFT 并集结果的解释（证据与局限）

- 观察：在六臂 MASE 中，单独 REFT 只在 TIME3、TIME4、TIME6 优于 CRB 和 UNI；FEV09 的最低值是 CRB+REFT，TIME2/TIME7 是 UNI+REFT，TIME1 是 CRB，TIME8 则是 ORI。因此不能概括为“选出来的数据普遍不如 REFT”。
- 强证据：并集训练的 reference 暴露量被 source 池稀释。每个 source 选择集为 638,202 窗口；训练固定 4,000 步、batch=32，即 128,000 次窗口抽样。src 与 ref 拼接后，训练代码用 `rng.integers(0, len(windows), size=batch_size)` 有放回均匀抽样（`src/rage/experiments/train_eval.py`）。因此单独 REFT 的 128,000 次抽样全部来自 ref；并集里 ref 只按行数比例抽到下表的期望次数：

| 任务 | ref 窗口数 | 并集中的 ref 比例 | 并集 128,000 次抽样中 ref 期望次数 |
|---|---:|---:|---:|
| FEV09 | 4,766 | 0.7412% | 949 |
| TIME1 | 3,250 | 0.5067% | 649 |
| TIME2 | 4,227 | 0.6580% | 842 |
| TIME3 | 13,332 | 2.0462% | 2,619 |
| TIME4 | 4,131 | 0.6431% | 823 |
| TIME6 | 259,085 | 28.8743% | 36,959 |
| TIME7 | 1,577 | 0.2465% | 316 |
| TIME8 | 61 | 0.0096% | 12 |

- 所以 (1) 的方向是“ref 在并集中相对 source 太少”，不是 ref 窗口绝对数量普遍很大。TIME6 的 ref 确实有 259,085 个，但仍占不到并集的三成；小 ref 任务在单独 REFT 中被大量重复抽样（例如 TIME8 平均每个 ref 窗口被抽约 2,098 次），并集则几乎不给 ref 梯度更新机会。重复训练既可能帮助适配，也可能过拟合；仅凭 MASE 无法区分。
- (2)“ref 与筛选 source 相似度低”仍是可能原因，但目前不能确证。筛选只保留 source 窗口对 task-specific ref block directions 的 top 10% 最大梯度余弦，入选阈值因任务约为 0.1523–0.3984；该量来自探针梯度方向，不是原始值/时序分布相似度，也不是下游收益。selection.json 只记录阈值和入选数，没有持久化全体 source 窗口 score。本次另对入选集合抽样重算了分数分布，但未入选集没有对应抽样，因此仍不能比较两组分布，也不能证明阈值代表“足够相似”。
- 其他可能因素：固定 4,000 步使更大的并集没有更多优化步数；source 与 ref 的梯度匹配用稀疏 q8 锚点和 max-over-reference-block 聚合，局部最高匹配可能不代表整个任务分布；source/ref 的尺度、趋势或季节性差异可能让联合目标产生梯度冲突；并集训练集目前按行数自然加权，没做 ref 过采样；任务评估和训练均为单 seed，部分差异很小，现有结果没有方差或显著性证据。窗口是否跨 source/ref 重复也未做去重核验。
- 当前最直接的结论是：ref 在并集训练里的抽样权重被数量比例大幅压低，这是已验证的机制；低相似度、目标冲突和过拟合是待验证假设，不能单独归因。可用固定更新步数对照 ref/source 加权采样，并记录每个 arm 实际抽到的 ref/source 次数；同时保存完整 cosine score 摘要、分组训练 loss，并用多个 seed 估计不确定性。
