### 总体判断

1. 在长轨迹（230,161 窗口，统计最稳定）上，预算相同的严格均匀锚点在全部六档 q 上给出更高的平均余弦；最长区间二分没有稳定优势。
2. 相对 L2 的方向不一致：q=8/16 二分更好，q=4/32/64/128 均匀更好，幅度在 −0.0146 至 +0.0258 之间。
3. 二分布局确实带来了明显的非等距性（gap CV ≈ 0.30），但这一非等距性并未转化为重建收益；均匀的 `余弦≥0.9` 占比在长轨迹 q=4 上明显更高（0.9721 对 0.9169），其余档位两者接近。
4. 这与历史 `v0-crb-reconst-fine` / `v0-crb-reconst-test` / `v0-crb-mech-test` 的结论方向一致：在固定锚点预算下，简单均匀布点通常优于自适应或二分式选点。
5. 短轨迹只有 153 个窗口，且高 q 时退化到两端点，不能用于支持或否定上述结论。
