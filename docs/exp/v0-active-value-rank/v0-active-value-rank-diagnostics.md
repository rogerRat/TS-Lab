# v0-active-value-rank 诊断扩展

最后修改日期：2026-11-09

状态：批次 3-proxy-coverage 和 4-equal-budget-query 已完成。所有输出均为对缓存的全梯度余弦和输出头余弦分数的回溯性重放。未训练或计算任何新模型或梯度。

## 输入与决策规则

100 个固定参考和十条源轨迹与已完成的 v0-active-value-rank 批次 1 和 2 相同。每个参考有 714-766 个跨轨迹、步长为 16 的候选；平均为 721.8。被保留的参考起点被排除。对于每个参考，k=ceil(0.10n)，因此 k 随候选数量变化，而非固定为 72。稳定的降序分数排序按现有候选顺序解决完全并列。Recall@k 是所选集合与全梯度 oracle top-k 集合的交集除以 k。结果对参考 recall 等权平均；每条参考轨迹有十个参考。

跨参考来看，平均有 29.22 个真实 top-k 窗口位于 proxy 排名 1-k，17.87 个位于 k+1-2k，10.70 个位于 2k+1-3k，5.79 个位于 3k+1-4k，3.79 个位于 4k+1-5k，5.33 个位于 5k 之后。65 个参考至少有一个真实 top-k 窗口位于 5k 之后；14 个至少有十个。参考 70 是一个极端案例：在 k 时覆盖率为 0.0411，在 3k 时为 0.1233，在 7k 时为 0.5753。因此许多被漏掉的窗口位于 proxy 列表靠前的位置，但仍存在大量严重的排名偏低。仅靠边界查询规则无法在较小预算内恢复那些遥远的窗口。

全部 7,270 个真实 top-k 候选的排名记录在 batch-3/true_top_proxy_ranks.csv 中。Batch-3/coverage.csv 包含每 10 个候选的步进以及 k 的倍数；batch-3/rank_bins.csv 包含六个分箱。batch-3/figures/reference-NN.png 中的 100 张图分别展示每个参考的覆盖率曲线和排名分布。Batch-3/coverage_summary.csv 记录跨参考覆盖率，同时不隐藏最小值和中间值。

## 批次 4：等预算查询比较

在 B=0 时，所有方法都对原始头部 proxy 排序，平均 recall 为 0.4023。对于 B>=8，所有方法都以批次 2 中已使用的相同八个 proxy 分位数标签开始；这些标签计入 B。纯边界依次访问 proxy 排名 k,k+1,k-1,k+2,k-2 等，跳过已选择的标签。Proxy high 访问排名 1,2,3 等，同样跳过初始标签。Random 在每个参考的 30 个带种子的排列中访问一个。这三个方法用精确的缓存全量分数替换被查询的 proxy 分数，并保持未查询分数为原始值。现有复杂方法使用批次 2 的 ridge 残差修正、预测不确定性和边界效用，对被查询点使用精确分数。其保存的逐参考批次 2 recall 行被原样复用。所有四个方法使用相同的候选池、目标、评估、预算和初始八个标签。

| 预算 B | 纯边界 | Proxy high | Random，30 个种子 | 现有复杂方法 |
|---:|---:|---:|---:|---:|
| 0 | 0.4023 | 0.4023 | 0.4023 | 0.4023 |
| 8 | 0.4048 | 0.4048 | 0.4048 | 0.3617 |
| 16 | 0.4214 | 0.4130 | 0.4083 | 0.4293 |
| 32 | 0.4482 | 0.4336 | 0.4152 | 0.4764 |
| 64 | 0.5064 | 0.4776 | 0.4295 | 0.5415 |

复杂方法减纯边界 recall 在 B=8,16,32,64 时分别为 -0.0431、+0.0078、+0.0282 和 +0.0352。复杂方法的相应参考胜/平/负计数为 31/9/60、47/8/45、59/4/37 和 58/3/39。在 B=64 时，复杂方法在 10 个参考轨迹均值中的 9 个上优于纯边界，有一个轨迹均值为负。其平均增益在此固定重放上是真实的，但并未支配每一个参考。在 B=8 时，共同的校准模型比简单的原始分数替换更差。

在 B=16,32,64 时，Random 种子均值在 30 个种子上的样本标准差分别为 0.00076、0.00137 和 0.00227。在 B=64 时，最差和最好的种子均值为 0.4252 和 0.4343。B=8 的 Random 重复完全相同，因为整个预算就是共享的初始集合。尽管跨参考的种子均值变异性很小，Random 的逐参考平均值仍可能很差。

## 解释与局限

Proxy 作为候选筛选是有用的，但对许多参考会漏掉遥远的真实 top-k 窗口。纯边界是一个有意义的简单基线，在 B=16-64 时优于 proxy high 和 random。现有复杂方法在八个标签时更差，在十六个标签时略好，在此同池重放上于 32-64 时更明显地更好。该证据支持在中等预算下保留复杂方法以进行进一步留出测试，同时保留简单的边界基线，并在依赖狭窄候选池之前调查 proxy 排名偏低问题。它目前不足以支持引入新模型或新查询策略。

两个原始分数都是同一数值范围内余弦相似度。跨参考来看，全量减头部的分数偏移均值为 0.0176；逐参考分数标准差的均值全量为 0.1484，头部为 0.1565。因此三个简单策略的原始分数替换是可解释的，但 proxy 与全量分布并不完全相同。复杂方法被允许使用其现有的学习修正作为被测组件；按设计，它对未查询分数使用不同的估计。此比较未将修正模型与其查询策略隔离开来。100 个参考共享十条轨迹，部分步长为 16 的窗口在原始观测中重叠。在早先方法开发之前未预留留出参考。这些是描述性的同样本结果，而非独立显著性证据或下游训练证据。

## v0-active-value-rank 诊断扩展

最后修改日期：2026-11-09

在与早先 active-value-rank 研究相同的 100 个参考和缓存候选分数上完成了批次 3-proxy-coverage 和 4-equal-budget-query。平均 true top-k 覆盖率在 proxy 池 k,2k,3k,4k,5k,7k 时分别为 0.4023、0.6480、0.7950、0.8744、0.9265 和 0.9754。真实 top-k 窗口在 proxy 排名分箱 k+1-2k、2k+1-3k 及 5k 之后的平均数量分别为 17.87、10.70 和 5.33；65/100 个参考至少有一个真实 top-k 窗口位于 5k 之后。Proxy 漏检并不局限于紧邻 k 的边界。

在 B=64 时，平均 Recall@k 为纯边界 0.5064、proxy high 0.4776、random（30 个种子）0.4295 和现有复杂方法 0.5415。复杂方法减纯边界的差值在 B=8,16,32,64 时分别为 -0.0431、+0.0078、+0.0282 和 +0.0352。这是在早先研究所用相同参考上的缓存分数重放；不产生留出声明或下游训练收益。逐参考表、图、方法和局限：docs/exp/v0-active-value-rank/v0-active-value-rank-diagnostics.md。输出：outputs/train/v0-active-value-rank/batch-3 和 batch-4。
