# 正整数预算最小总量搜索（五个已完成样本）

用户要求三项均为整数百分比、每项>=1%、总和<=30%，总预算越少越好。
本轮用原五任务各一条rank0完整轨迹（105086窗口）检验严格逐任务平均余弦>=.90。
所有计算仅CPU读取现有梯度，模型反传0次，未停止或重启原扫描。

按总量从3%逐档穷举。3%到17%的全部680个正整数三元组均有判定证据；
最难的Darwin优先验证，未过线即可否决三元组，无需计算其他任务。
仅在生产CRB实际证明没有分裂/预算丢弃/抵消区间时，复用同cover/error不同split
的完全相同结果；非重复CRB计算136次，枚举耗时13.03秒（不含加载）。
各块对逐窗单位梯度的点积和使用FP64前缀和，与逐窗余弦均值数学等价；
12项数值/完整枚举测试通过，并用原逐窗方法独立复核13/1/1、14/1/1、15/1/1。
