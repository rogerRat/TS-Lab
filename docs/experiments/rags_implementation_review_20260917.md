## 最终公式

对参考轨迹 i 的块 b，n_ib 是该块拥有的合法起点数，N_i 是该参考轨迹的全部合法起点数。块代表为两端锚点梯度的均值，即线性插值在几何中点的值；余弦使用其单位方向。

    w_ib = n_ib / N_i
    S_j = sum_i sum_b w_ib * cosine(d_ib, d_source_j)
    P_j = exp(S_j / T) / sum_k exp(S_k / T)

每条参考轨迹内部的块权重之和为 1；所有参考轨迹贡献直接相加，不除以参考轨迹数或参考块数。最终概率没有源块长度因子。当前三个模型的 rags_gateless、rags_global 与 lessvg_t025 均配置 T=0.25，均对原始总分做全局 Softmax，保留非正评分。

## 原实现与描述的差异及修改

| 项目 | 原实现 | 本轮修改 |
|---|---|---|
| 主块级 RAGS 的竞争机制 | 每个参考块独立 Softmax，再按参考预算混合；低匹配参考也必须贡献自己的质量 | 先汇总所有参考块的评分，仅做一次全局 Softmax；删除逐参考概率预算 |
| 参考块权重 | 原主方法在概率混合阶段用 n_ib / sum_all_reference_blocks(n)；原 Global 在评分阶段使用相同全局归一化 | 在评分阶段使用 n_ib / N_i；每条参考轨迹总权重严格为 1 |
| 参考聚合尺度 | 原 Global 是按所有参考合法起点数归一化的加权平均 | 各轨迹内部加权后跨轨迹求和；不再除以总参考数/总窗口数 |
| 最终源质量 | 指数质量乘源块合法起点数 m_j | 直接 Softmax(S/T)，不传源块计数 |
| 非正余弦/评分 | 旧 rags、rags_t025 使用 positive gate，旧 gateless/Global 不使用 | 本轮块级评分统一保留有限非正分数，与当前 LESS 主臂一致；无 rank 映射 |

## 核查后无需修改的环节

- 三个预算仍来自同一 CRBConfig.budgets：分别取整、端点计入覆盖预算、小轨迹预算裁剪不超过合法起点数。
- 覆盖阶段：先两端，再二分当前最长区间；允许批量处理同长度区间。
- 误差阶段：曲率 κ=2||g_mid−g_linear(mid)||/[(mid−left)(right−mid)]，风险=(right−left)^5 κ²/120；优先最高风险，计算中点后更新子区间。尚未测量曲率时使用当前乐观估计。
- 分裂阶段：所有可分裂区间进入最小中点范数队列；同分最小 frontier 可以批量计算；后续继续使用剩余预算，直到预算耗尽或不存在可分裂区间。中点优先级来自端点线性插值，不额外计算所有候选中点。
- p10 仍计算并保存阶段1/2锚点范数阈值审计；当前块级流水线没有用该阈值限制分裂、提前停止、过滤块或丢弃窗口。
- 线性重构采用锚点的紧凑表示，不创建全部窗口×4096维的稠密矩阵；块代表已是端点梯度均值，无需额外中点梯度计算。
- 块起点采用半开所有权，最后一个块包含最终端点，使所有合法起点恰好归属一个块。这里的“长度比例”明确采用合法起点所有权比例，不是原始时间点数或重复计入共享端点的包络长度。
- 选中源块后，仍在其全部合法起点内均匀抽取窗口。

## 审核时需要注意的边界

1. **源块等权竞争不等于源轨迹等权竞争。** 在所有块同分时，每块概率为1/B；一条轨迹有B_i个块，其总概率为B_i/B。本轮严格执行用户的块级 Softmax 描述，没有额外按源轨迹块数归一化。
2. 主块级 rags_gateless 和 rags_global 现在采用相同公式，属于同一方法的两个入口；后续实验不应将其当作不同机制的独立证据。
3. 本轮范围是块级族 rags/rags_t025/rags_gateless/rags_global，以及使用同一评分入口的 rags_uniform。轨迹级 rags_traj/rags_traj_gls/rags_traj_global 尚未依据新描述修改；其逐参考预算或全局均值/源长度因子仍需独立审核。
4. 裸 rags/LESS 等历史配置仍可能使用不同温度或 legacy LESS rank。当前主实验对比明确是 rags_gateless/rags_global 对 lessvg_t025，三模型均T=0.25。
5. 参考评委等权及源质量删除长度因子，记录为适应目标 Benchmark 评估单位的决策。用户认为真实场景应根据长度/时间点频次加权；本实验选择不替代这一立场。
