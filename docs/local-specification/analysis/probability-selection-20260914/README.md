## 1. 问题定义与预算

给定同一可行源池的合法窗口集合 Ω，每个方法输出训练前固定的概率分布 q(w)，q≥0、Σq=1。训练从该分布有放回抽样，使用相同模型、损失和更新日程。硬选择是特例：选中集合内均匀，外部为零。候选支持可以大于名义召回量；它是真实可访问的数据，单独报告其大小，不再称为只选择了 N 个窗口。

这是离线确定分布、训练时抽样，不要求随模型更新概率，也不需要实时重新检索。抽样后正常计算平均损失，不再乘一次 q；不加 1/q 去恢复全池均匀目标。

三个量独立记账：

- **候选规模控制量 M**：RAGS 沿用源点数单位，局部目标为 Mπ_j，按排名保留完整源块直到首次达到目标；小于一个块也保留第一个块。M 控制候选范围，不保证实际支持等于 M。候选耗尽时记录不足；整个合法候选池为空时无法定义训练分布，明确报错。
- **训练抽取量 T**：实际更新次数乘 batch size，统计重复抽取。沿用现有日程时，steps=ceil(4N/32)，T=32·steps；N 仅是旧日程的换算参数，不再代表唯一数据量。“4 轮”只是名义曝光刻度，不是遍历新支持四遍。
- **选择成本与实际支持**：梯度/嵌入计算、代理训练、检索时间、索引大小、唯一合法起点数、唯一原始点覆盖、召回关系数分别报告。大支持本身可以是方法优点；数据效率的结论必须对应实际支持或实际训练消耗。

主表所有方法共用同一个池文件与指纹；改变 T 或 M 时不随之重抽或扩大池。既有池可以继续用，本文不另设池容量。训练量曲线和候选规模曲线分开画。正式数值在开发集标定后冻结，不根据测试结果挑参数。

## 2. RAGS 的概率输出

保留参考块 j 的份额 π_j=n_j/Σn，其中 n_j 为合法起点数；既有弱信号和不可表示区域过滤不变。令 A_j 为该参考块召回的源块中合法起点的集合，m_k 为源块 k 的合法起点数，则

q(w)=Σ_j π_j · 1[w∈A_j]/|A_j|。

按参考块、源块、起点三级抽样正好实现此分布。每个入口内部源块不重复且起点唯一归属，跨入口同一个窗口的概率相加，物理数据可只存一份。向上保留完整块不会改变 π_j：候选变多只影响入口内部的分布。

例如 20 个等份参考入口、总共抽 2 次：各入口单次概率为 1/20，期望使用次数为 0.1；可以各保留至少一个候选。有限两次训练必然有许多入口未被抽到，这是实际抽样的限制，不等于把它们从可选集合删除，也不保证每次运行恰好满足比例。

保证的是保留参考入口的**期望份额**；源语义类别份额和最终效果还取决于匹配质量，不能从公式直接推出。

## 3. 基线逐项适配

**评分粒度约束（2026-09-14 用户确认，概率适配不得改变）。** LESS 与轨迹级单次估值仍以整条轨迹评分；TSDS 仍以整条轨迹作为嵌入、OT 与概率分配单位；LP-Mirror 仍按窗口评分；LTSV 保留块估值→点汇总→窗口分数的原有链条；RAGS/Ours 仍以 CRB 块表示梯度并进行参考块—源块匹配。概率转换只使用这些已有分数或质量，不新增更细粒度评分，不改变参考聚合、块边界或既有过滤规则。轨迹/块级方法先选原单位，再在其内部均匀抽合法窗口，不得在内部重新评分、排序或择优。以下统一窗口概率公式仅描述最终训练抽样，不将各方法改造成窗口级选择。

统一的是分布输出和训练接口，各方法保留自己的打分依据和参考聚合方式。不能把所有基线都改成 RAGS 的逐参考块匹配，再声称是原方法比较。

| 方法 | 当前代码 | 下一版概率部署 |
|---|---|---|
| Random | exp 已在全可行源池合法起点上在线均匀抽样；dev 仍固定挑不相交窗口 | 全池合法窗口均匀抽样，不先限制到 N 个；作为最宽支持的基础比较 |
| TSDS | 已输出轨迹概率 p_i，但随后多项抽取轨迹副本、洗牌、累计点数截断，再对留下的窗口均匀抽 | 直接按 p_i 抽轨迹，再在轨迹内均匀抽窗；去掉中间副本和点数截断。每个窗口概率 p_i/n_i，不能再把轨迹概率乘一次长度 |
| LESS（现有轨迹适配版） | 各参考轨迹单位梯度分别与源轨迹匹配并求和，按分数取整轨迹至点预算 | 保留原评分；比较可调大小的 top 集合均匀抽样，以及统一的排名概率部署 |
| 轨迹级单次估值 | 先平均参考轨迹原始梯度再归一化，源轨迹按余弦排名 | 保留该聚合方式，采用与 LESS 相同的两种部署；它仍是完整流程对照，不能说只改变了 RAGS 的粒度 |
| LP-Mirror | 代理适配前后损失差打分，按窗口分数取前 N | 保留全部窗口分数；比较可调 top 集合与排名概率部署，集合大小独立于训练次数 |
| LTSV | 块估值汇成点分再汇成窗口分，按窗口分数取前 N | 保留原估值与汇总；对窗口排名采用同样的两种部署 |

TSDS 的概率赋值和有放回采样是其[原论文 §2.3](https://papers.nips.cc/paper_files/paper/2024/file/13848b5893119ff772b69812c95914fa-Paper-Conference.pdf)已有设计。原论文先抽成训练数据；这里直接用于每次训练抽样仍是部署适配，需要披露。我们的轨迹特征、学生模型等既有适配也继续披露。

### 排名方法共用一个简单的概率转换

四个只给分数的基线同时保留以下两种版本，避免只让 RAGS 享有扩大候选与非均匀抽样的能力：

1. **Top-support**：按原评分排序，保留指定范围，在其中所有合法窗口上均匀抽样。支持范围独立于 T，并允许扩大到整个已评分池。轨迹级按整轨迹加入，不拆轨迹评分。原来固定 N 的部署保留作历史对照。
2. **Rank-probability**：所有已合法评分的窗口都可抽到，排名越靠前概率越高。将原评分转换为合法窗口上的排名百分位 r(w)，使用 q(w)∝exp(-r(w)/τ)，τ 控制集中程度；τ=∞ 为均匀抽样。相同分数用同一中位排名；轨迹内部不另算分数、所有合法起点并列同分；按合法起点数计数仅用于已有轨迹排序到抽样概率的换算，不能区分同一轨迹内窗口的优劣。

因此轨迹级排名概率实现为 P(i)∝n_i·exp(-r_i/τ)，再轨迹内均匀采窗。这里分数是每个窗口继承的偏好；TSDS 的 p_i 已是整条轨迹的概率质量，不能套用此长度乘法。两者的单位必须在产物里明确。

排名转换避免直接把不同方法量纲各异、可能为负的原始分数当概率；它是本实验统一增加的适配，命名时加上部署后缀，不能宣称属于原论文。窗口分数若计算失败，不得静默当低分；方法定义的合法性过滤单独记录。

Top 范围、τ 与 RAGS 的候选规模控制量都只在既有开发划分选择，预先列出搜索表并给相同的训练试验次数。保留两种基线的结果；如主表只放一个部署，按开发集选定，不能测试后择优。具体网格尚未冻结，不在此次文档修改中凭空设定。

## 4. 最少需要的干净对照

主比较固定共同池、参考边界、学生起点、模型损失、训练抽取次数、batch、学习率规则及种子数；各方法保留自己的估值计算，并报告实际成本。共同的调参机会不等于要求所有方法输出相同概率或相同支持。

另做三项可解释对照：

1. **同一份 RAGS 支持、两种概率**：合并后的唯一合法窗口均匀抽 vs 新 q。候选内容完全相同，区分权重贡献。
2. **相同分配与采样、不同块构造**：CRB vs 均匀锚点/固定分块，保持参考份额和候选规模规则一致，控制梯度预算。区分细粒度估计的贡献。
3. **同训练量、候选范围曲线**：RAGS 的局部候选范围与基线的 top 范围分别扩大，报告实际唯一覆盖。另给共同实际覆盖目标的比较，整块导致无法精确匹配时报告误差；不是只比名义 N。排名概率版另画集中度敏感性。

每次实验至少记录实际支持、实际抽到的不同窗口/唯一点数、重复率、训练抽取总数。可附有效窗口数 1/Σq(w)²；RAGS 必须先把跨参考入口的同源窗口概率合并后计算，不能对关系条目直接算。该数只说明概率集中程度，不等于统计独立样本量，不能消除窗口重叠。

旧选集上的事后分组重加权只能验证那个具体干预，不能替代新召回与 q 的实验。现有结果不证明新方法有效，也不构成拒绝概率选择的依据。
