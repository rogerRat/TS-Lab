## 1. 问题：协议绑死导致的两难

全部流程（打分、训练、考试）固定在 576 窗口协议（C=512/H=64，域 A1）。Intro（`_rags-0901.md` 问题一/二）需要论证：细粒度滑窗估值相对"把整个样本吃进单个输入上下文、对平均损失做一次反传的聚合估值"有对应优势。但该对照没有显然的单对实验设计：

- 考生是长上下文模型：平均估值自然可算，但窗口级估值只能用别的小窗口代理模型 → 差异可被归因到模型本身不匹配（性能错配）；
- 考生是短上下文模型（现状）：窗口级估值自然可算，但"整样本单上下文"不可表达——Chronos-T5 硬上限 512，越界即位置嵌入 OOD，不可用；
- 用另一个模型做长上下文平均估值 → 差异又可被归因到协议不同（模型与协议同时变了）。

三种单对设计的共同缺陷：每次比较都**同时换了两个东西**。

## 2. 分析：混淆可拆成两个正交因子

| 因子 | 是什么 | 由谁决定 |
|---|---|---|
| 条件长度 | 每个预测点能看到多少历史 | **模型属性**，被部署钉死：考生 Chronos-small 512 上限、考卷 512/64、训练 576 窗。不是估值方法的自由变量 |
| 打分聚合深度 | 一次打分平均掉多少个预测事件（Intro 问题一自己的定义，`_rags-0901.md:60`） | 估值方法的**唯一真正的自由变量** |

三个推论：

1. **训练与考试协议不是本对照的自由变量**。它们被部署唯一确定（A1 统一合同、FEV 考卷适配、512 上限）。正确问法是"固定部署下，估值协议如何影响选择信号质量"，不是"两种端到端系统谁好"。
2. 两难的隐含假设是"每种估值协议必须由其原生模型来算"。放弃它：长上下文模型上**两种协议都可算**；短模型上的"整样本平均"有梯度线性性给出的忠实等价物 = 轨迹内全部窗口梯度的均值（`_exp-0907.md:302` 已写此恒等式，当时作为被否决的臂；本文档的重算不重开该否决——否决的是主表臂实现，不是机制层重算）。
3. 短模型与长模型版本之差恰是条件长度这一个因子，可被单独测量。

## 3. 拟议设计：2×2 因子（附录）

四个估值臂；**考生、训练日程、考卷全部不动**（冻结的 Chronos-small 流水线），只有估值模型与切片方式变。不建第二条训练流水线。

| 臂 | 估值模型 | 条件长度 | 聚合深度 | 成本 |
|---|---|---|---|---|
| W512 | Chronos-small | 512/64 | 逐窗 | 已有（主表 RAGS 信号的最细极） |
| S512 | Chronos-small | 512/64 | 整段/整条均值梯度 | **近乎免费**：机制层在已存完整梯度上重算分歧（零反传）；主表实现载体 = §8α 整轨均值臂（与段级臂共享同一次反传，零新增） |
| W2048 | 长上下文代理 | 段内最长条件，逐 64 目标窗打分、不平均 | 新算，选择开销小 |
| S2048 | 长上下文代理 | 段内最长条件，整段一个平均分（Intro foil 的忠实实现） | 新算，选择开销小 |

各对照的读数与归因消解：

- **W2048 vs S2048**：同估值模型、同考生，只差聚合深度 → "归因到模型不匹配"在此结构上不可能成立。foil 主对照。
- **W512 vs W2048**：同协议，只差估值模型 → 把"代理模型效应"从推断变成被测量的因子；补报两者分数秩相关，顺带堵"小窗打分对长模型是否 in-distribution"。
- **S512 vs W512**：同模型内聚合深度效应 = 机制一"聚合-逐窗排名分歧"（`_exp-0907.md` §3.2）加一行"整段均值"聚合器，机制二抵消发生率按深度分层 → 机理层证据，免费。
- **S512 vs S2048**：聚合相同时的条件长度效应。

审稿人无论把差异归到哪个因素，表中都有一行是"固定该因素后差异仍在/消失"的直接读数。

## 4. 长上下文"整段平均"的实现注意

- Chronos-Bolt 解码器固定 64 目标输出，"整段吃进、整段平均"**不原生**；最接近版本（整段条件、只预测末 64 点）把"平均"混淆成"recency"，不可用。
- 忠实实现 = **上下文移位**：段内取多个目标窗，每次预测条件于段内该目标之前的全部历史（至上下文上限），段分 = 各前向梯度的均值。Chronos-2（8,192）/ TimesFM 2.5（16K）等直接预测模型均可。
- 代理模型挑选标准：**两种协议都能原生表达**。同家族（Chronos-2）控制预训练配方差异；跨家族（TimesFM）加泛发性；二选一，不必都做。
- 参考侧梯度须在同一估值模型下重算（同臂内共享参考聚合）；选择侧池子按 LESS 方式子采样（成本适配披露话术照抄 F1）。
- 考试协议**冻结不动**（512/64 考卷）；"原生 FEV 全历史长上下文考卷"是另一个部署问题，划出范围。

## 5. 论文措辞（最便宜的一步，先做）

主张"**打分聚合深度**影响选择质量"，不主张"**短窗口**估值优于长上下文估值"。理由：上下文指数变长（`_rags-0901.md:60`），"短窗口好"会被领域方向证伪；"无论模型吃多长，每样本一个分，段内结构被求平均压掉"（`:64`）与"上下文照样可以长，打分照样可以细到窗口，两不耽误"（`:76`）是协议无关的。三种结果的退路：

| 结果 | 读法 |
|---|---|
| S2048 < W2048 | 主张得证且无混淆（预期主结果） |
| S2048 ≈ W2048 | 靠机制一分歧统计 + 抵消发生率解释聚合何时起作用（`:100` 已撤回强主张，退路现成） |
| S2048 > W2048 | 不致命：说明长条件携带窗口估值拿不到的信号 → W2048 应两头都赢，"两不耽误"措辞保住论点结构 |

Intro 的 foil 明确定义为"聚合深度在固定部署下的影响"，协议一致版本的粗极用 S512 实例化——主表的粒度阶梯（轨迹级 → RAGS → 完整扫描）已是该主张的直接检验；2×2 是给较真审稿人的附录弹药，不是主表前提。

## 8. 轨迹级臂失配核查（2026-09-08）

核查对象：远程 `/root/TS3` 在 2026-09-08 13:17 之前的代码形态（`granularity_select` 版，即产出 `_exp-0907.md` §7 实测数字、与本地冻结提交 `82761ee` 对应的那一版）。该版文件已于当日 13:17–13:25 被新版覆盖（见 8.4）；新版落地后本节结论须复核一遍。

### 8.1 代码事实

- 段级臂每个 576 段**独立**一次前向+反传（`side_gradients`/`batch_gradient_sketch`），与 RAGS 的锚点/插值梯度零共用；实测 21,688 次 vs RAGS 508,094 次反传（≈23×）。
- 粒度两臂打分 = cos(对象梯度, **单一全局参考均值方向**，`ref_grads.mean(axis=0)` 归一化)；RAGS = 26,592 个参考块**各自作查询、top-B 检索**，窗口分 = 覆盖它的返回对的最大余弦——两臂不止差聚合深度，还差检索拓扑。
- `_trajectory_objects`：每段恰 1 个继承起点（段首槽位），候选格与 Random 的 `disjoint_slots`（起点 1+j·576）**精确同格**——`_exp-0907.md:125` 的拍板等价性声明在代码上成立。
- 部署 `cut_disjoint`：全局分数贪心、允许跨轨迹挑段、装满 N。召回对象是段，不是整条轨迹。

### 8.2 判定

- 对"统一部署下的信号比较"定位：**不失配**，且当前实现优待粗臂（允许跨轨迹挑好段；严格整轨召回不许挑，只会更差）——偏差方向保守，安全。
- 对"只改变打分的聚合深度"主张（`_exp-0907.md` §2.1 粒度对照）：**失配**。轨迹级→RAGS 同时改了三个变量：(i) 聚合深度；(ii) 预算 K（15→352 次/条）；(iii) **匹配拓扑**（全局单方向 vs 逐块 top-B）。现有阶梯没有任何一格能把 (i) 与 (iii) 分开——比预算更隐蔽的混淆，审稿人可三选一归因。
- "轨迹级"命名失配：召回/部署单位是段（`:125` 已自认名不副实）。

### 8.3 修法

- **(α) 加"整轨均值"臂，零新反传**：轨迹平均梯度 = 段梯度算术均值（段梯度在 `granularity_select` 内存中已有；时间均匀加权，与 `:302` 恒等式同族，仅权重约定之差，不重开 k 抽样否决）；打分 cos(轨迹均值, 参考整轨均值)（参考侧逐轨迹等权聚合）；召回 = 轨迹按分排序、整条取其全部槽位、到 N 截断。与段级臂**预算严格相同**（同一次反传不多花），唯一差别 = 聚合深度 + 召回单位——即 §3 的 S512 格的实现载体，一臂两用（粒度阶梯受控粗极 + Intro"整样本平均估值"的协议一致实现）。
- **(β) 段级臂改名**（"段级/单窗估值"）。论证链变为：Random→段级 = 梯度选择本身（同格不变）；段级→整轨均值 = 聚合+召回粒度（同预算受控）；整轨均值→RAGS 的剩余差 = 预算 + 自适应细粒度 + 逐块检索，由 (γ) 与机制层拆解。
