# 全可行源池重采样：N、评分单位与训练口径

**远程实现核对（2026-09-15）。** `ssh exp:/root/TS3` 的 `src/rags/crb.py`（`_interval_mean`、`_make_block`）先取原始端点梯度的算术平均 $\bar g_I=(g(a)+g(b))/2$，再按实际非零范数归一化为 $v_I=\bar g_I/\|\bar g_I\|_2$；范数以 float64 计算，方向保存为 float32。匹配使用 $s_{jk}=v_{R_j}^{\top}v_{S_k}$。不先逐窗口单位化再平均，也不乘块内一致性系数 $\kappa_{R_j}\kappa_{S_k}$。该代表是线性插值的连续区间平均，不等于左闭右开离散窗口集合的精确平均；原始端点幅值仍会影响平均后的方向。

## 1. N 就是可行源池大小

固定窗口长度 W=C+H=576。可行源池轨迹长度为 L_i，沿用现有池构造代码的窗口当量计数：

$$N=\sum_i\left\lfloor\frac{L_i}{W}\right\rfloor.$$

这与 exp `src/rags/experiments/data.py` 的 `accumulated += len(values) // window_length`、池 manifest 的 `total_equivalents` 一致。逐轨迹折算，不跨轨迹拼接；余下不足 W 的点不计一个完整当量，但它们仍可出现在合法的滑动窗口中。

N 不等于逐点滑动的合法窗口总数。后者另记为 A=Σ_i max(0,L_i−W+1)，用于窗口索引和采样计数。N 在各方法特有的估值过滤之前、由共同池计算；不能因为 Ours 删除了弱信号块，就给 Ours 换一个更小的 N。池文件确定后，N 从实际 manifest 读取，不能写死为旧的4096，也不能由目标构池下限代替实际值。

主实验的任务是：**为可行源池内所有单位计算重采样分数或概率，各方法继续使用自己的评分单位。** 不再另设子集大小、选择比例、源点数召回目标 M、局部配额 Mπ 或面向子集的 top-K 截断。旧硬子集方法只能作为明确标注的历史/机制对照，不作为当前主协议的另一种可选部署。

全池参与估值不要求每个单位有正概率。既有合法性过滤保留；使用梯度对齐分数的方法，其评分后的置零规则为对齐分数≤0，正分不得再人为置零。Ours按参考块—源块配对执行，细节见§3。TSDS等不输出梯度对齐分数的基线仍保留原生概率算法，不为执行此规则额外计算梯度或改变评分单位；原生零质量另报。不得用“全池”之名更改方法核，也不得在概率计算后另加保留率截断。TSDS 原有近邻检索参数属于其概率算法，不是新设的子集大小。

## 2. 评分粒度保持不变

| 方法 | 原有单位与流程 | 全池重采样方式 |
|---|---|---|
| Random | 无评分，合法窗口 | 全池合法起点均匀抽 |
| LESS | 每条轨迹一份梯度估计/分数，保留自身参考聚合 | 对全部轨迹的已有分数转换概率；抽轨迹后，轨迹内均匀抽窗口 |
| TSDS | 每条轨迹一个嵌入和 OT 质量 p_i | 直接按全池轨迹概率 p_i 抽，轨迹内均匀抽窗；每窗口为 p_i/n_i |
| LP-Mirror | 每个合法窗口的代理损失下降分数 | 全池窗口分数转为概率后直接抽窗口 |
| LTSV | 块估值→点汇总→窗口分数 | 保留完整估值链条，最终全池窗口分数转概率 |
| Ours/RAGS | CRB 重建及校验后，参考块与源块的方向匹配分数 | 对全部保留源块分配条件概率，先抽参考块，再抽源块，最后块内均匀抽窗口 |

不新增轨迹内/块内窗口评分，不按窗口分数细筛轨迹或块，也不把轨迹均值、CRB 块或 LTSV 既有汇总方式相互替换。概率换算使用合法起点数，仅涉及质量计量，不增加估值分辨率。梯度型方法仍保留原计算密度；TSDS 等非梯度评分方法不被强制计算梯度。

### 2.1 窗口级基线的实施决定（2026-09-14）

**用户已确定：LP-Mirror 和 LTSV 暂时保留原生估值机制，最终输出窗口级估值，理论上覆盖共同可行源池的全部合法窗口。先按此方案实施主实验；只有实际耗时确实不可接受时，再讨论修改。** 本条是实验实施决定，不代表本地或远程代码已在本次更新中修改，也不代表全池估值已经完成。

- **LP-Mirror**：保留轻量线性代理训练、参考侧适配，以及适配前后窗口损失差的估值流程；对全部合法源窗口分批前向评分，不新增源侧抽稀或插值。
- **LTSV**：保留源块的一步参数更新、更新后参考损失评估及参数恢复，再按块→点→窗口汇总；覆盖全部合法源窗口，不要求每个滑动窗口都独立反传。已有 RAGS/LESS 投影梯度缓存不能直接替代这套更新与重新评估机制，也不把它改成梯度内积近似。
- **原生的边界**：保留各方法的估值内核及其既有块、窗口和参考评估设置；统一模型、C/H、参考可用范围和从估值到重采样概率的协议适配仍需披露，不能声称完整复现原论文所有实验设置。全部窗口参与估值不等于全部窗口获得正采样概率；须检查窗口覆盖，缺失或非有限分数另报，不能静默跳过。
- **公平性与成本**：保持共同源池、可用参考范围和同模型内冻结的下游训练预算；不为追求相同估值耗时而改变估值粒度。分别记录代理训练、源侧估值、参考重评估、概率构造和下游训练成本，以及吞吐、峰值显存、缓存存储、完成单位数与合法窗口覆盖率；方法允许复用的产物同时披露首次成本和复用成本。
- **后续调整条件**：先取得实际耗时、吞吐和剩余工作量，再判断主实验总耗时是否可接受。目前不设置额外的源侧估值预算上限，不提前切换稀疏评分、插值或轨迹级替代；如确需调整，先提交原因和备选方案，确认后单独标明近似版，不能与原生版结果混报。

LESS 和 TSDS 继续保持轨迹级，不因本条而改为逐窗口估值。以上决定只固定当前两条基线的实施路线，不自动增补其他基线。

**轨迹消融更新（2026-09-14，用户已确认）**：旧独立 `trajectory_level` 臂移出主表，以 RAGS-Traj 消融取代。它直接复用 RAGS 梯度缓存，按重建规则对应的合法窗口贡献加权成轨迹均值，去除自适应加密计算导致的计数偏倚；不重新均匀采点，不对缓存记录直接平均。参考轨迹保持独立查询及原质量份额，沿用 RAGS 的评分、门控和逐参考概率归一化；源轨迹内均匀抽窗。详细定义、支持域与可行性检查见[实验文档 §5.1](_exp-0907.md)。此为设计更新，不是代码已完成。

## 3. Ours 不再先选一批块

参考过滤规则不变。保留参考块 j 的合法起点数为 n_j，π_j=n_j/Σ_r n_r。对所有保留源块 k 计算原有块间分数 s_jk；源块合法起点数为 m_k。给定评分到非负权重的单调函数 h，定义：

$$P(k\mid j)=\frac{m_k h_+(s_{jk})}{\sum_l m_l h_+(s_{jl})},\qquad
q(w)=\sum_j\pi_j\frac{h_+(s_{j,k(w)})}{\sum_l m_l h_+(s_{jl})}.$$

第二式适用于属于保留源块的合法窗口；被既有规则过滤的窗口为零。块的起点唯一归属规则保留，原始包络重叠不重复创造起点。抽样步骤为 π 抽参考块、P(k|j) 抽源块、块内均匀抽合法起点。

**非正对齐置零（2026-09-14用户决策）。** 对通过既有合法性和方向可表示性检查、已有有效对齐分数的配对，严格使用

$$h_+(s)=\begin{cases}0,&s\leq0,\\h(s)>0,&s>0.\end{cases}$$

下述概率公式中的h一律取h_+。因此在可行的参考行内，P(k|j)=0当且仅当s_jk≤0；正对齐配对不得因排名低、保留率、额外阈值或数值量化而被置零。按方法定义将非正对齐视为需要排除的信号，其中零分也排除；这是一条基于当前块代表梯度的算法判据，不是逐窗口真实效用的证明，不新增块内评分。

置零发生在**每个参考块—源块配对**上。某源块对参考A非正、对参考B为正，只删除它在A入口下的贡献；仍可从B入口被抽到。对全部保留参考都非正的源块，最终源概率才为零。既有弱信号/不可表示过滤在评分之前执行，不在本次改动中取消；无有效分数或非有限数值不能当作“余弦≤0”，须作为检查失败处理。

每个保留参考块必须至少有一个s_jk>0的源块，才可能同时满足此规则和Ref份额守恒。若整行非正，报告该参考块及其π份额，并将当前分布构造标为不可行；不能删除该参考再归一化π、重抽其他参考、回退均匀或给非正配对补小正数。此时不生成可用于正式训练的概率产物。

可行时，仅在正对齐配对上归一化，再乘该参考原π份额：Σ_k π_jP(k|j)=π_j仍严格成立。先置零后局部归一化，不能在混合后的源分布上再筛一遍而破坏Ref贡献。

**Ref比例是硬约束（2026-09-14用户确认）。** 在既有参考过滤之后，按保留参考合法起点数计算π；不能改为参考轨迹等权、参考块等权，也不能按源池匹配质量改变π。定义参考到源块的联合质量

$$a_{jk}=\pi_jP(k\mid j),\qquad \sum_k a_{jk}=\pi_j,\qquad P(k)=\sum_j a_{jk}.$$

因此任意参考组G对最终源分布贡献的总质量严格等于Σ_{j∈G}π_j。Ref的三组份额若是50%/25%/25%，三组分给源池的总权重也必须是50%/25%/25%；最高相似度、梯度模长、匹配源块数量和源池原有配比都不能改变这一比例。匹配只决定每组把自己的份额分给哪些源块。

必须先将每个参考查询的条件分布归一化为1，再乘π并求和。禁止对π_j m_k h(s_jk)在全部参考—源块配对上只做一次归一化：它会把参考份额改成与π_j乘本查询总权重成比例，再次偏向容易匹配的参考。跨参考共享源块时贡献相加，不取最大值，不因去重而丢贡献；最终混合之后不再作改变相对权重的截断或非线性重加权。概率舍入、缓存及采样器也必须保持该不变量。

这是概率质量的确定性约束，不只是观察抽样直方图“差不多”。有限训练抽样的入口频次允许统计波动；源语义分组是否与Ref同配比另做匹配有效性检查，不能用入口守恒冒充源类别守恒。原过滤不因本约束改变，过滤前后Ref份额与覆盖须同时报告。

不能简单把旧候选集合改成全池，再只按块长度抽样：那会使匹配分数失效，退化为保留源区域均匀抽样。h 必须使用原匹配信号。正区间最简开发候选为 h(s)=exp(s/θ)，θ>0；非正区间由h_+明确置零；在每个参考查询内用数值稳定的归一化计算。该映射与温度数值是待开发验证的部署参数，不改变方向余弦评分，也不是本次用户另行指定的参数。

对于排名基线，沿用此前建议的全池排名概率转换，取消 Top-support 主协议：用已有单位分数的排名转换单调权重；轨迹级按合法起点数换算轨迹质量，单位内均匀抽。TSDS 的 p_i 已是轨迹质量，不再乘长度。各方法以相同开发训练次数标定转换参数，不使用测试集选温度；原评分、嵌入或估值内核不变。

分布在训练前确定，训练中只抽样，不随学生更新重新打分。正常平均损失，不再乘采样概率或做逆概率修正。

### 直接按源块概率抽样的等价实现

先抽Ref、再抽源块、最后抽窗口是方法的定义；静态部署可将Ref这层提前求和。记 $p_{jk}=P(S_k\mid R_j)$，源块的边缘概率为

$$\beta_k=\sum_j\pi_jp_{jk}
=\sum_j\frac{n_j}{\sum_r n_r}\frac{m_k h_+(s_{jk})}{\sum_l m_l h_+(s_{jl})}.$$

预先计算并保存β，训练只做两步：按β抽源块k，再在该块m_k个合法起点中均匀抽一个窗口。任一窗口w属于源块k时，

$$P_{\mathrm{direct}}(w)=\frac{\beta_k}{m_k}
=\sum_j\pi_jp_{jk}\frac{1}{m_k}
=P_{\mathrm{hierarchical}}(w).$$

因此两条路径的窗口分布完全相同，这是全概率公式的直接求和，不是近似或新的优化问题。β已经包含源块长度因子，抽源块时不能再乘一次m_k；取窗口时才除以m_k。也不能先把各参考的余弦平均再置零/归一化，必须先按配对置零、逐参考归一化、乘π，最后累加。

“按长度抽Ref”仍指保留参考合法起点数。若实现先抽参考轨迹i，再抽该轨迹内参考块j，则轨迹权重用N_i^ref=Σ_{j∈i}n_j，块内权重用n_j/N_i^ref，两级相乘恰为π_j；不能对参考轨迹等权，也不能把上下文包络长度重复算进去。

**静态部署优先保存源块边缘概率。** 可以逐参考计算完整源块概率行，将π_jp_j累加到β；检查该行非空和质量守恒后继续处理下一行。训练产物只需β、源块身份/合法起点索引与必要元数据，不必保存完整参考×源块概率矩阵；两种实现都不要求在训练中读取Ref、重新匹配或更新概率。另保存π、行归一化与符号检查记录、池/块/评分配置身份，供验证来源份额。分块计算不会消除原有匹配计算，所省的是训练时的Ref抽取与完整条件表存储。

直接源块抽样没有实际Ref入口标签，验收先检查β=Σ_jπ_jp_j、Σ_kβ_k=1和各行联合质量Σ_kπ_jp_jk=π_j，再检查抽样的源块/窗口频率。不能凭β本身反推各参考贡献已经正确；生成过程必须通过行守恒检查。保留三级路径作小规模对照：两者要求分布等价，不要求同一随机种子生成逐样本相同的序列。

某参考行没有正对齐候选时，必须在边缘化前报告不可行；不能通过直接源块抽样把缺失Ref份额掩盖掉。对全部Ref均非正的源块β=0；有正贡献的块β>0。既有块边界、评分单位、符号规则和Ref比例约束全部不变。

## 4. N 与训练次数必须分清

训练实际抽取量记为 B，更新次数为 U，batch size 为 b；满批运行时 B=Ub。全池等效曝光轮数 E=B/N。它是计算量刻度，不保证遍历每个窗口或每条轨迹一次。

设定 E 后，更新数可按 U=ceil(EN/b) 换算，并报告满批取整后的实际 B。此前 N_old=4096、E_old=4、b=32 对应512步、16,384次抽取，是**历史训练量**。若新 N 约20,480，仍取 E=4 就约为2560步，计算量约增至五倍；旧标定不能证明该训练量合适。

因此先以相同实际 B 比较新旧采样，再在开发集标定全池口径 E；旧学习率、损失、窗口协议可作为起始设置，不能把原“最多4轮”自动宣称为新口径已标定结论。本次未启动更长训练，也未改远程配置。

- 本轮不做固定分块、随机初始化、窗口级返回、去检测、直接丢弃、四格交互、同支持均匀采样或放松 Ref 份额的下游消融；不追加密度/阈值等扫描。Ref 份额仅做方法约束的正确性验收，不宣称其独立预测收益。主表既定结果与成本披露保持，不因本条增加曲线训练任务。
