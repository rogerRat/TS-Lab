# Intro 完整结构 DAG

两项技术挑战对应计算与表示两项方法贡献；实验是独立回答层，不作为第三项技术挑战。研究缺口处提前提出保真与价值问题。

    B1["§1 预训练选择<br/>质量、覆盖、多样性、去重、配比；相似来源未必有益，真实／合成数据改变迁移。"]
