有 3,162/83,330 个向量范数大于 10。最大范数对应缓存 loss 4346.32；另有 loss 19520.36、范数 150.21 的锚点。极端范数与高 loss 同现，当前证据不能判定为缓存损坏，应在阈值设计中保留这些真实重尾值或单独做数据质量核查。

对缓存分量抽样统计：中位数约 -5.8e-6，P25/P75 约 -0.00613/0.00607，P1/P99 约 -0.1387/0.1367；样本中位于零附近的分量很多，但没有精确零值。分量分布存在明显重尾，抽样极值约 -15.19 至 10.06。

### 梯度方向夹角

- 从粗锚点中抽样 43,200 个向量，随机形成 150,000 对锚点方向余弦：均值 0.00468、标准差 0.09221，中位数 0.00211，P1/P99 为 -0.22976/0.27359。
- 同轨迹、相邻 q=32 起点共有 81,157 对；方向余弦均值 0.15827、中位数 0.15354、P25/P75 为 -0.00174/0.31777。邻近锚点存在明显依赖。
- 各向同性独立 4,096 维高斯向量的余弦标准差近似为 1/sqrt(4096)=0.015625，角度标准差近似 0.895 度。该理论尺度明显小于缓存方向的实测随机配对标准差，不能直接作为实际粗梯度的噪声阈值。

## 对 ADS 设计的含义

1. 用“角度高于 90 度”或“余弦大于理论期望 0”直接选点会保留大量随机正余弦；当前 ADS 使用每个 source 锚点对 reference 的最大余弦，匹配方向应使用单侧上尾显著性。
2. 不宜直接用 4,096 维各向同性高斯的解析方差。缓存方向分布更宽、分量重尾，且相邻锚点相关。
3. 阈值应作用于每个 source 锚点的 max-reference 分数，并在零假设中使用同一个 reference 锚点数和 max 聚合；否则 reference 数量较多的任务会因取最大值而天然获得更高分。
4. 建议以现有真实粗梯度构造经验零分布：每次对 reference 梯度坐标施加独立 Rademacher 符号翻转，保留向量范数及 reference 侧内积结构，同时打乱 source-reference 的坐标对齐；对每次随机化仍计算每个 source 的 reference 最大余弦。由该零分布得到每个 source 锚点的上尾 p 值，再用预先声明的误报控制水平筛选，取代 rho=0.2 的固定配对比例。随机化重复数、误报水平和依赖校正需要在正式实验配置中冻结。
5. 通过零假设筛出的粗锚点作为精算种子；沿现有 vicinity 规则计算附近细锚点。第一版可保留 R=1 与 h=4，仅替换 rho 选择机制，以便把变化限定为阈值策略。细锚点继续使用相同零假设检验，不再按固定比例截断。
