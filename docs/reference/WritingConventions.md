以一个Python包或者一个对应命令/脚本作为一个核心环节的执行入口，并围绕此命令介绍使用方法。
必须以Markdown表格的形式介绍命令的所有CLI参数（如果他使用CLI）或者该命令的配置文件格式，以及对应的文件位置。
Markdown表格必须包含以下基本元素：
参数变量名称（如--num-workers,CLI或者num_workers,config files）-含义解释-示例-是否必须-默认值-允许的输入值类型(list,str,float,int...)，
Markdown表格必须每一个参数单独一行，不允许混叠。禁止使用无序列表等其他方式进行参数说明。必须有参数说明表格，且只能以表格形式进行。

文本禁止堆砌代码变量名和内部概念。在提出一个变量名和内部概念之前，必须对它进行先解释。
文本追求对逻辑链条清晰的表达（如何时对数据做了什么处理，加载数据的逻辑），而不是对具体代码实现算法的重新表述（如使用了SQLite或者其他技术栈，具体的代码实现使用了什么包装器装饰器）。
