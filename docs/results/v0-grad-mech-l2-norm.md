# 相对 lag-L2 梯度距离

最后修改日期：2026-11-08

状态：已完成。这是 v0-grad-mech-l2-norm 补充实验，仅针对十条保留的 M5 轨迹：源 manifest 序号 973、980、981、984、985、987、988、996、998 和 999。它覆盖同一固定已预热 ChronosTiny checkpoint 上的 12,836 个合法窗口。原始 1,000 轨迹的 grad-mech 结果仍然独立。

## 指标与来源

对于每一对梯度 g_i 和 g_(i+k)，R = ||g_i - g_(i+k)||_2 / ((||g_i||_2 + ||g_(i+k)||_2)/2)。R=0 表示梯度完全相同；R=1 表示它们的差值等于平均梯度范数；R 最大为 2。配对在同一轨迹内，涵盖从 1 到 575 的每个 lag。Lag 1 表示 575/576 = 99.83% 的窗口跨度重叠。

包含全部 8,394,496 个梯度坐标。源梯度以 FP32 计算并以 BF16 保留。该补充实验使用由这些 BF16 缓存导出的现有全梯度 Gram 矩阵。Gram 构造使用 FP32 分块矩阵乘积，并在坐标分块间进行 FP64 累加。平方 L2 为 G_ii + G_jj - 2G_ij，分母使用 sqrt(G_ii) 和 sqrt(G_jj)。未计算任何新模型梯度。

## 结果

主要的 lag-1 结果有 12,826 对。其按对加权的平均 R 为 0.6372，中位数 0.7620，RMS 0.7771，p90 1.1571，p95 1.2411。十个轨迹均值的平均为 0.6462；各轨迹均值范围为 0.4801 到 0.8052。

描述性地看，1563/12826（12.1862%）的 lag-1 对具有 R<0.1，而 3951/12826（30.8046%）具有 R>=1。这些是描述性参考水平，而非预先注册的假设阈值。

## 结论

经验性局部相对平滑假设在这十条保留轨迹上被反驳。即使在 lag 1，相邻窗口共享 576 个时间点中的 575 个（99.83% 跨度重叠），但成对相对全梯度 L2 距离的均值为 0.6372：在这种成对归一化的意义上，梯度差范数平均约为两个梯度平均范数的 64%。中位数为 0.7620；55.01% 的 lag-1 对具有 R>=0.6，30.80% 具有 R>=1。在这个选定样本中，这是一种常见的大幅相对变化，尽管十个轨迹均值从 0.4801 到 0.8052 不等。

对于相同的十条轨迹和相同的 12,826 个 lag-1 对，由缓存的全梯度 Gram 矩阵重建的按对加权余弦均值为 0.7215（等轨迹均值 0.7173）。原始 1,000 轨迹的 grad-mech 余弦均值在不同范围下为 0.7539。约 0.7 的余弦描述的是部分方向对齐；它并不确立完整梯度的 L2 变化很小。因此，早先认为 lag-1 方向相似性支持局部相对平滑的解释，不被直接的相对 L2 测量所支持。

该结论涉及固定模型、checkpoint、损失、预处理和十条选定 late-manifest 轨迹下的小相对梯度变化。它并不证明梯度映射在数学上非 Lipschitz：此类断言需要指定输入空间距离和界限。窗口共享原始时间点，但偏移的上下文和目标仍可能产生显著不同的梯度。

## 检查与范围

全部十个源 manifest、BF16 缓存完成标记和文件大小，以及 Gram 矩阵形状、有限项、对称性和正对角线均通过验证。三十个抽样配对距离直接从 BF16 缓存重新计算（每条轨迹三个）；与 Gram 导出的 L2 的最大绝对差为 0.00001966。没有负的平方距离需要截断。5750 个轨迹-lag 行和 575 个合并 lag 行具有有限指标；lag-1 对数与 12,826 个保存值一致。

这十条轨迹是从原始固定 1,000 轨迹 manifest 的未处理尾部选出的，用于梯度保留。它们不是全部 1,000 轨迹的代表性重跑。窗口对存在重叠且相互依赖，因此对数不得被解读为独立样本量，也不得用于配对独立的 p 值。BF16 保留和 Gram 相乘引入有限的数值误差；直接配对检查评估了此计算，但不恢复原始 FP32 梯度。窗口重叠比例不是输入空间距离，因此 R 本身并不证明 Lipschitz 连续性。

## v0-grad-mech-l2-norm

于 2026-11-08 作为 v0-grad-mech-test 的十轨迹补充实验完成，使用保留的 BF16 全梯度缓存及其全坐标 Gram 矩阵。在 12,826 个 lag-1 对中，按平均梯度范数归一化的相对 L2 距离按对加权均值为 0.6372，中位数 0.7620，p95 为 1.2411。十个轨迹均值的均值为 0.6462。全部 575 个 lag 和 30 个直接缓存配对检查均通过验证。在这十条轨迹中，经验性局部相对平滑假设被反驳：尽管 lag-1 跨度重叠为 99.83%，每个配对的梯度差范数除以该配对平均梯度范数的均值为 63.7%，且 55.0% 的配对相对距离至少为 0.6。同十轨迹的 lag-1 余弦均值为 0.7215；约 0.7 的方向对齐并不确立小的全向量 L2 差异。该结果仅限于十条保留的 late-manifest 轨迹，不能替代原始 1,000 轨迹汇总，也不证明数学上的非 Lipschitz 性。完整报告：docs/results/v0-grad-mech-l2-norm.md。结果产物归档于 archive/v0-grad-mech-test/outputs/train/v0-grad-mech-l2-norm/；outputs/train/v0-grad-mech-l2-norm/ 仍为符号链接。十个 BF16 梯度缓存未归档，仍位于 outputs/train/v0-crb-reconst-test/gradients/。
