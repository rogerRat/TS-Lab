# TimerXL 64轨4096维投影梯度的逐轨主成分

最后修改日期：2026-11-12

## 目标与数据

仅分析 TimerXL LoRA 的64条真实4096维投影梯度轨迹，不把 pooled/global PCA 作为结论依据。源缓存为 BF16 投影，投影 seed 42；每轨按窗口序列中心化后计算自身协方差及 PC1。共有 1,980,371 个窗口，轨迹长度为150至230,209个窗口，轨迹长度差异明显。

主成分方向按无向轴处理：比较方向时使用绝对余弦，因此 (v) 与 (-v) 视为相同方向。每轨报告 PC1 解释方差比例和 PC1-PC2 方差间隔；轨迹间比较64个 PC1 的2016个两两夹角。稳定性以每轨前半段和后半段分别估计的 PC1 绝对余弦衡量。

## 结果

| 指标 | 结果 |
|---|---:|
| 每轨 PC1 解释率中位数 | 12.1% |
| PC1 解释率第10–90百分位 | 6.6%–32.4% |
| PC1 解释率范围 | 4.4%–82.9% |
| 每轨 PC1-PC2 方差间隔中位数 | 4.9个百分点 |
| 全64轨 PC1 两两夹角中位数 | 87.3° |
| 两两夹角第10–90百分位 | 76.6°–89.5° |
| 两两夹角大于60° | 1,944/2,016 |
| 前后半 PC1 绝对余弦中位数 | 0.843 |
| 前后半 PC1 绝对余弦大于0.8 | 35/64 |
| 前后半 PC1 绝对余弦小于0.5 | 18/64 |

筛选窗口数不少于4096且前后半 PC1 绝对余弦至少0.8的34条轨迹后，561个轨迹对的 PC1 夹角中位数为87.1°（第10–90百分位：70.8°–89.5°）；525/561个轨迹对的夹角超过60°。这表明方向差异并非只由所有短轨迹造成。

## 解释和限制

逐轨 PC1 的解释率通常不高，典型轨迹的变化并非由一个方向主导。64个 PC1 的两两夹角整体接近正交，稳定子集也保持这一现象，说明轨迹级主方向差异很大。

这属于方向差异的描述性证据，不是正式显著性检验。18条轨迹的前后半方向一致性很低；此外，高维 PC1 在样本较短或 PC1-PC2 间隔较小时容易不稳定。特别是少数仅有150至几百个窗口的轨迹，其 PC1 不能直接视为可靠估计。若需要 p 值或置信区间，应对每轨做时间连续块 bootstrap，再比较 PC1 夹角分布。

## 按合法起点长度归一化的 rank80

用户明确的长度定义为每轨合法预测起点数 (L_i)。本批梯度缓存选择 all_legal_windows，因此 `trajectory_pca.csv` 中每轨实际缓存窗口行数就是精确的 (L_i)，而不是从分段指标文件推导的长度。共64轨、1,980,371个合法起点；平均 (L_i=30,943.3)，中位数12,144.5。

令 (v_i) 为该轨达到80%累计解释率的最小PC数，逐轨计算 (v_i/L_i) 后，64轨等权平均为 **4.07%**，中位数 **1.63%**，第10–90百分位 **0.14%–11.39%**，范围 **0.010%–25.33%**。若将所有轨迹的方向数与合法起点数分别求和，(sum_i v_i/sum_i L_i=0.563%)；这与逐轨比例的算术平均是不同的汇总量。

注意：`k1_segments.csv` 仅保留完整分段，最后不足一段的尾部起点不会出现在该文件中，因此其最大末端值会低估 (L_i)。本节全部 (v_i/L_i) 均使用完整合法起点梯度缓存的逐轨行数，没有使用分段末端值。逐轨比例列表写入 `analysis/pca-spectrum/spectrum_comparison.json`。
